## Projetos em destaque

### NOC Intelligence GPC · Repositório privado

Desenvolvi uma plataforma para apoiar analistas de NOC na consulta de informações técnicas e no acompanhamento de tickets. O projeto reúne uma API Python, um painel web e uma extensão de navegador em um fluxo de atendimento.

Minha contribuição combina backend, interface e automação. O analista tem acesso aos resultados para revisá-los e mantém a decisão sobre como conduzir o atendimento.

**Tecnologias:** Python · FastAPI · React · JavaScript · Selenium

### Sonar Coletor · Repositório privado

Desenvolvi uma extensão Chrome para reduzir o trabalho de copiar e organizar informações técnicas durante o atendimento. A coleta parte de uma ação do analista na interface e organiza os dados para revisão.

O projeto aplica JavaScript e manipulação do DOM a uma tarefa real de suporte. A revisão faz parte do fluxo, permitindo que o analista confira o conteúdo antes de usá-lo.

**Tecnologias:** JavaScript · Chrome Extensions · DOM

### Auto GRC · Repositório privado

Desenvolvi uma extensão Chrome para automatizar etapas repetitivas de um fluxo operacional em uma aplicação legada. O operador inicia a execução na aba escolhida, acompanha o progresso e pode cancelar a automação.

O projeto demonstra como aplicar automação a uma interface existente e oferecer controles para que o usuário gerencie a execução.

**Tecnologias:** JavaScript · Chrome Extensions · DOM

### [App Produtiv](https://github.com/belchor007/proj-app-produtiv)

Aplicação web para gerenciar tarefas. Permite criar uma conta, fazer login e criar, editar, concluir e excluir tarefas.

**Tecnologias:** PHP · Laravel · Bootstrap

### Event Assist · Repositório privado

Desenvolvi uma extensão para Chrome e Edge que transforma os dados básicos de um incidente em um cadastro pronto para revisão. O preenchimento automatizado ajuda a padronizar o registro e reduz a digitação repetitiva.

O analista confere os valores e confirma o envio no próprio formulário. Esse controle permite automatizar a preparação do registro preservando a validação final de quem atende o incidente.

**Tecnologias:** JavaScript · Chrome Extensions · DOM
